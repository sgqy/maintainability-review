# maintainability-review

Review code for human handoff: trace features, clarify state ownership and refactor only when maintenance becomes easier.

面向人工接手的代码审查：追踪功能、明确状态归属，只做能降低维护成本的重构。

## Install / 安装

Run in your project root / 在项目根目录运行：

```sh
npx skills add sgqy/maintainability-review
```
